## 결론과 적용 범위

**SUMMARY 구현 기준을 근거로 추가로 표 전체를 A 원본 복제로 바꿀 후보는 0개다.** 원본 SUMMARY 192개 항목의 J열 구현 기준을 전부 읽고 대장 193행에 대응했다. 표 전체 미표시 93개 항목의 J열은 모두 「입력 화면에 표시하지 않음. 원본 시트/값 유지.」이며 대응 대장 94행 모두 이미 A 원본 복제·표기 안 함이다. DEMAND의 백업 1항목이 T-079/T-080 두 행에 대응한다.

표시 항목 99개 중 SUPPLY `LNG Summary`의 T-119도 이미 A 원본 복제·읽기 전용이다. 나머지 98개는 입력/구조 변경·연쇄 집계·부속 control 또는 미확정 분류이며, 구현 기준이 표 전체 원본 복제를 지시하지 않는다. 현재 미기입 9행을 A로 채울 근거도 없다. 직접 입력이 없다는 이유만으로 SUPPLY 연쇄 집계 T-107/T-108을 A로 바꾸지 않는다.

이 결과는 SUMMARY와 현재 분류의 대조다. 모든 A가 모델 미사용이거나 모든 미표시 계산열이 재계산 제외라는 의미가 아니다. 원본 보존의 업무 결정은 domain 정본을 따르며, 이번 비교는 대장이나 업무 정책을 변경하지 않는다.

## PriceModelInput 정본 차이 해결 — 2026-10-08 사용자 확인

최초 대조에서는 TRADE `4.5 PriceModelInput` T-183/T-184의 SUMMARY/대장 입력·C와 기존 domain 규칙 44/spec의 시트 전체 원본 보존이 충돌했다. 후속 사용자 확인으로 **SUMMARY대로 입력 편집·아래 행 추가 가능한 C가 맞으며 정본을 수정**하도록 결정했다.

업무 정책은 수정된 domain 규칙 44, 조회 응답/수용 기준은 [input-provision spec](../feature-specs/mi-fundamental-model-input-provision-feature-spec.md)을 따른다. 대장/원본은 이미 이 결정과 일치하여 변경하지 않았다. 기존 결정 변경 후보의 채택 여부는 해결됐으며 상세 write 계약·실파일 검증은 별도 잔여다. 같은 시트의 미표시 계산표 T-177~T-182는 기존 A 보존을 유지한다. 추가 표 전체 A 후보 0개라는 조사 결론과 아래 192개 구현 기준 원문은 변하지 않는다.

## 원본·대장 대응과 검증 근거

4개 원본 SUMMARY는 정규화 전 snapshot에서 읽었다. 운영 정규화본에는 개발 전용 SUMMARY가 없으며 이 조사 때문에 최종 XLSM에 추가하지 않는다. 워크북 밖 참조 설명인 SUPPLY T-129·TRADE T-192/T-193도 현재 A·미표시 기록과 일치하지만 복제할 XLSM 시트·셀을 새로 정의하지 않는다.

- OOXML 추출과 별도 openpyxl 읽기 결과의 SUMMARY A:J 1,920필드가 일치했다. 각 파일 J9가 `구현 기준`임을 확인했고 데이터 행은 DEMAND 10~88, SUPPLY 10~40, TRADE 10~73, OUTPUT 10~27로 누락/빈 구현 기준이 없다.
- 역할·시트·영문 표 이름으로 대응하고 DEMAND 백업만 명시적 1:2 대응을 적용했다. 193개 대장 ID는 중복/누락 없이 모두 대응했다.
- 원본 4파일 SHA-256은 manifest와 일치하고 읽기 전후 불변이다. 대장도 읽기 전후 hash가 같다. 상세 실행·명령은 stable work note에 기록한다.
- 셀 수식/의존성 재스캔·재계산·POI 시험·모델 실행을 이번 비교에서 수행하지 않았다. 조회·수정·재계산·원본 보존을 별도 정책으로 두는 공통 설계 방향은 유지한다.
